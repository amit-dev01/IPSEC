# Free No-VM Deployment Guide

Deploy the IPsec Analyzer without any VM/VPS, using managed free tiers.
You create **4 free accounts** and paste each service's connection value
directly into Render when asked. **Never paste secrets into chat, email, or
GitHub** — they go only into the provider dashboards below.

Total ongoing cost: closest to ₹0 — Neon, Upstash, and Cloudflare R2 have
standing free tiers; Render's API web service is free (sleeps when idle),
but **Render background workers are not free**, so the Celery/TShark worker
uses Render's cheapest `starter` plan. Budget roughly US$7/month for that
one item, or pause the worker when not demoing (analyses stay queued and
process when it restarts).

## Architecture

| Piece of the app | Provider | Your action |
|---|---|---|
| Code | GitHub (already have) | Merge the PR containing `render.yaml` |
| PostgreSQL database | **Neon** | Create 1 project |
| Redis queue | **Upstash** | Create 1 Redis database |
| PCAP file storage (S3) | **Cloudflare R2** | Create 1 bucket + 1 API token |
| API + Worker containers | **Render** | Create 1 Blueprint from the repo |

## Step 1 — Neon (PostgreSQL)

1. Sign up at <https://neon.com> → **New Project**.
2. Region: **Singapore** (closest to India). Name it `ipsec`.
3. Open **Connection Details** / **Connect** and copy the connection string.
4. Change only its beginning and keep the rest identical:
   - From: `postgresql://user:pass@host/dbname?sslmode=require...`
   - To: `postgresql+psycopg://user:pass@host/dbname?sslmode=require...`
     (just insert `+psycopg` after `postgresql`).
5. Keep this string ready for Step 4. Do not share it anywhere else.

## Step 2 — Upstash (Redis)

1. Sign up at <https://upstash.com> → **Redis → Create Database**.
2. Name it `ipsec`, pick the closest region offered, create.
3. In the database details, copy the **`rediss://...` URL** (TLS form,
   shown under Connect / endpoint details).
4. Keep it ready for Step 4.

## Step 3 — Cloudflare R2 (PCAP storage)

Note: Cloudflare may ask for a payment method to enable R2 even on the
free tier — the free allowance (10 GB storage) is what this app uses.

1. Sign up at <https://dash.cloudflare.com> → **R2 Object Storage**.
2. **Create bucket**, name exactly: `ipsec-captures`.
3. Go to **Manage R2 API Tokens → Create API Token**:
   - Permission: **Object Read & Write**, scoped to the `ipsec-captures` bucket.
4. Copy three values and keep them ready for Step 4:
   - **Access Key ID**
   - **Secret Access Key** (shown only once)
   - **Endpoint**: `https://<your-account-id>.r2.cloudflarestorage.com`
     (shown on the R2 overview page; your account ID, not a secret by
     itself, but treat the keys above as secrets).

## Step 4 — Render (runs the app)

1. Sign up at <https://render.com> → **New → Blueprint**.
2. Connect your GitHub account and select the `IPSEC` repository
   (the `render.yaml` file at the repo root defines both services).
3. Render will ask for the values marked `sync: false`. Paste:
   - `IPSEC_DATABASE_URL` ← Step 1 string (with `+psycopg`)
   - `IPSEC_REDIS_URL` ← Step 2 `rediss://...` URL
   - `IPSEC_S3_ENDPOINT_URL` ← Step 3 endpoint
   - `IPSEC_S3_ACCESS_KEY` ← Step 3 Access Key ID
   - `IPSEC_S3_SECRET_KEY` ← Step 3 Secret Access Key
   (`IPSEC_JWT_SIGNING_KEY` is generated by Render automatically.)
4. Apply the Blueprint. The API runs migrations automatically on boot,
   then starts; the worker starts with the TShark image.

## Step 5 — Create your first login

There is no public registration (by design). Create the first
organization + admin once, using Render's **Shell** for the `ipsec-api`
service (Dashboard → ipsec-api → Shell):

```bash
ipsec-admin create-org-admin --organization "My Lab" --email you@example.com
```

It prompts for a password (typed interactively, never stored in chat or
env vars). Then log in via the API:

```bash
curl -X POST https://<your-render-url>/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"<the password you just set>"}'
```

## What to tell the assistant (safe to share)

Only these non-secret facts:

- "Neon / Upstash / R2 / Render done" (yes/no per step)
- Your public Render URL (e.g. `https://ipsec-api.onrender.com`)
- Any error message text you see (copy the text — screenshots fine too,
  after checking they show no keys/passwords)

## Never share

Passwords, the Neon connection string, Upstash URL, R2 secret key,
JWT keys, or Render/GitHub tokens — with anyone, including this assistant.

## Known limitations of this free stack

- Free Render API sleeps when idle: first request after idle is slow.
- Free tiers have small limits (Neon 1 GB DB, R2 10 GB) — plenty for a
  demo; PCAP files live in R2, not the database.
- Image digests are still unpinned (see `docs/runbook.md`).
